# 访视与冻结定义

样例均为虚构编号，无身份信息。受试者入组日期由subjects表唯一确定，记录中的入组基准必须完全一致。采样日期和入组日期均转为Asia/Shanghai日历日期，差值为访视日；时刻先统一UTC。
方案选择按当前受试者assignment和该次发生时刻查半开生效窗，匹配必须唯一，不能使用全局最新方案。v1访视V1=[5,10)、V2=[12,17)；v2为[6,11)、[13,18)。受试者00001于10月10日转v2，其他受试者仍用v1。
PRIMARY计入访视完成，RETEST只替代该次测量值。首次记录必须唯一且在访视窗内。缺首次访视、重复首次和窗外访视均阻断，复检不能填补漏访或消除原偏离。
复检须引用同受试者同访视的PRIMARY，晚于原采样且不超过72小时，版本必须更高。同最高版本复检冲突时保留原结果并阻断。所有检验值以mg/dL输出，g/L乘100。

## 参考范围双轨依据与毒性分级

每条检验结果按 `centers`（受试者→中心）、检验项目 HGB 和采样时刻，在 `reference_ranges` 中查半开生效窗 `[start,end)` 内的唯一中心范围，作为判定范围 `adj_range_id`。生效窗匹配为零或多于一条、中心未登记、下限不小于上限、毒性阈值缺失，均为证据不足：分级置 `UNDETERMINED`，写入 `range_blocks` 并阻断锁库，不允许猜测或沿用全局最新版。中心新版范围在生效日之前不追溯历史样本，10月采样仍命中11月才生效的旧版窗口。

毒性分级只允许依据判定范围，按 `toxicity_bounds` 的 ULN/LLN 倍数半开区间计算（下界含、上界不含），结果为 0-3 整数；低于下限即 1 级，命中更深倍数逐级上调。分析方统一新版范围由 `harmonized.range_id` 指定（中心为 `*`），仅用于跨中心比较，输出 `harm_*` 字段，绝不参与分级、偏离、复检或锁库。比较范围缺失或冲突只在 `harm_note` 提示，不构成阻断。

复检裁决选定结果回写同一份 `adj_range_id/adj_version/toxicity_grade/basis`，保证分级、偏离、复检、锁库与冻结封印同结论；冻结包 evidence.json 含全部 `range_results` 与 `range_blocks`，封印覆盖范围依据。

## 范围更正重算与回执

`POST /api/runs/{run_id}/range-recompute` 凭 `receipt_id` 与 `overrides`（深合并入范围上下文）重算不可变输入快照。回执先独立落库；计算成功才写入新批并把旧批置为“已失效”，旧批历史分级原样保留可审计。计算抛错或新批存在 `range_blocks` 时，批次事务整体回滚、旧批保留旧版分级，回执标记“失败”并记录原因，可凭同一回执重试。同一回执重试返回首次登记的新批，绝不新增分级或批次；回执绑定其他批次返回 409。范围更正只接受新增/替换式深合并，不通过空值删除既有登记。

锁库须所有规定访视完成，无偏离、复检问题、隔离行和范围阻断。冻结包包含每条选定结果、原始行号、方案版本、访视窗与范围依据。此工具只验证试验数据完整性，不做诊断判断或生产锁库。
